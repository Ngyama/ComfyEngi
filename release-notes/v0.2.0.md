## ComfyEngi v0.2.0

首个 Windows 安装包版本。

- 套图任务：角色 / 第二角色、动作序列、剧情场景、全局 Prompt，任务级 LoRA 配置与最终工作流预览
- 执行队列：逐张冻结快照、断线等待、中断恢复、失败重试
- 任务输出：文件名前缀（支持 %date:yyyy-MM-dd%），生成后复制最终图片到任务输出目录；复制失败可单独重试保存
- LoRA 管理、角色库、剧情库、素材库（Markdown 工作区）
- 设置：生成默认值、工作流管理、运行与恢复、数据与维护，关于与手动检查更新

安装：下载 `ComfyEngi-0.2.0-setup.exe` 运行即可，无需安装 Node.js。安装包未签名，SmartScreen 提示时选择「更多信息 → 仍要运行」。
